# V0.2.0 Report

## Resolved

- [x] Atomic writes on Windows (cache, history, FS transport → `util::atomic_replace`)
- [x] Vault settings rebuild missing `date_format` row
- [x] `serde_yaml` removed
- [x] Default config placeholder syntax (`{{bean}}`)
- [x] Version bump to 0.2.0
- [x] API key moved to `secrets.toml` (env var → secrets.toml → config.toml fallback)
- [x] API key auto-migration from config.toml to secrets.toml on first load
- [x] Percent-encode API URLs for vault paths with spaces
- [x] `config_version` serde default via `#[serde(default)]`
- [x] Leading zeros in config_version rejected
- [x] Empty `one_of = []` rejected at parse time
- [x] `add_field_on_disk` serializes `show_when`, `allow_create`, `wikilink`, `create_template`, `post_create_command`
- [x] `validate_form` skips hidden fields
- [x] `partition_fields` filters hidden field values from output
- [x] `clamp_active_to_visible` for form navigation
- [x] Duplicate YAML key when user field named "icon" (guard added)

## Open Bugs

- [ ] __Strftime injection__ — `render_path` and `render_append_template` expand `%` in user values
- [ ] __YAML escaping__ — `format_scalar` doesn't escape newlines, backslashes, or YAML reserved words
- [ ] __Comma-in-value splits to list__ — `", "` in icon/field values produces YAML list instead of scalar
- [x] ~~API key env var leak~~ — resolved by secrets.toml; api_key no longer written to config.toml
- [ ] __Duplicate field names in modules__ — sub-field/template duplicates checked, module-level not; causes silent HashMap overwrite
- [ ] __FS transport path traversal__ — no `..` check at transport layer (config validates at load, but no defense-in-depth)
- [ ] __`prefix_len` byte vs display width__ — non-ASCII prompts cause cursor drift
- [ ] __`eprintln!` during raw mode__ — garbled output in `autocreate.rs`
